- Owner-Diagnose: Das größte Problem ist heute, dass „Auftrag" und „Spiel" wie **zwei unterschiedliche Sachen** wirken — daher die vielen Missverständnisse. Diese Trennung wird aufgehoben: Auftrag = das Spiel.
